# Proyecto taller

Aplicación universitaria para gestionar perfiles, usuarios, vehículos, servicios y órdenes de servicio.

- Backend: `backend/taller` (Java 21, Spring Boot y MySQL).
- Frontend: `frontend/frontend-taller` (React, TypeScript y Vite).
- Esquema inicial: `database/database.sql`.

Consultar [configuración, endpoints, ejemplos y pruebas del backend](backend/taller/README.md).

Consultar [ejecución del frontend, exportaciones y reportes](frontend/frontend-taller/README.md). Usar `npm ci` dentro de `frontend/frontend-taller`, no en la carpeta superior.

Publicación de React y Spring Boot en Render con MySQL de Aiven: [guía de despliegue](DEPLOY_RENDER.md).
